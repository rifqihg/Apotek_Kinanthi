# Skill: shadcn-vue Helper

## Description
Instruksi khusus untuk pengelolaan komponen UI menggunakan shadcn-vue di proyek Vue 3 / Inertia.js.

## Rules & Commands
1. Gunakan selalu CLI `npx shadcn-vue@latest add <nama-komponen>` untuk menambah komponen baru.
2. Semua komponen UI wajib berada di folder `resources/js/Components/ui/`.
3. Pastikan kode yang ditulis menggunakan Vue 3 Composition API (`<script setup>`) dan berbasis `radix-vue` / `reka-ui`.
4. Jangan pernah menggunakan sintaks atau dependensi React.
